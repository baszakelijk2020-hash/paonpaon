Level I

At its most basic level, the following tool classifies a customer's body type into one of multiple predefined silhouettes, using only image processing.

MUNRO

Each silhouette corresponds to an anticipated set of FitTools, highlighted as a recommendation.

Level 2

At a deeper level, the tool analyzes the individual customer, identifying the FitTools specific to him.

1/2 Chest Width

Rotate Sleeve

Collar Roll

Level 3

Over time, aggregated data from thousands of fittings trains the tool to predict not only which FitTools are expectedly required, but also the values at which they should be applied.

Using machine learning, the tool evaluates how a Try-On initially fits a customer and correlates this with the set of FitTools applied to achieve the final result.

All above tools aim to minimise the number of clicks required per order, reduce fitting time, and limit switching between the customer and the screen.

Together, this preserves the customer’s energy and attention span, which could support upselling and improve other performance indicators.
